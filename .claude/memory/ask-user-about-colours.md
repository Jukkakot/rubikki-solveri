When an investigation is unsure what a sticker's or a face's real colours are in a picture (a still, a
recording's read picture, a screenshot), send those pictures to the user (SendUserFile, a few at a time, each with
a short numbered question) and ask; the user offered (2026-10-12) to tell what the cube really shows.

**Why:** the camera's colours (red/orange, washed-out white/yellow) and the finder's lattices can be misleading,
and guessing the truth wrongly sends a fix the wrong way; the user has the real cube at hand.

**How to apply:** before building on an assumed truth in a finding, if it is not certain from the cube's known
state or from several agreeing scans, ask with the pictures. Recordings hold only the face readings, not the camera
picture, so use stills, screenshots or the user's video where pictures are needed.
