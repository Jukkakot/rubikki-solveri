## ADDED Requirements

### Requirement: Check a scan
When opened from a scan, the manual input screen SHALL start with the scanned colours, mark the
stickers the scan was unsure about or that cause a problem, and show a note asking the user to
check the marked stickers. Marks SHALL clear once the user changes the cube.

#### Scenario: Opened from a scan
- **WHEN** the scan was unsure about two stickers
- **THEN** the editor shows the scanned cube with those two stickers marked and the note
